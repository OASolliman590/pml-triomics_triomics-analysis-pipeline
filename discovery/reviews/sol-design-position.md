# Sol first-round design position

Date: 2026-09-06. This is an independent settlement proposal for the Sol–Opus exchange. “Settle” below means my recommendation is specific enough to adopt; it does not claim user acceptance or agreement with Opus. Scientific behavior still marked by an empirical gate must fail closed until that gate passes. The approved facts are the clinical-association scope and the existing protected invariants. R remains a recommendation awaiting the user’s language confirmation.

## Clinical decisions

**CL-ADR01 — settle.** Adopt one typed clinical schema: dictionary, subject, visit, observation, observation-to-sample link, derived definition and objective registry. Each value binds original source position/hash, concept, type, unit/conversion, codes/missing codes, qualifier/censoring, visit/time and verification. Similar IDs never establish linkage. Unknown meaning/unit, conflicting static values, ambiguous visit or unreviewed multi-response decoding makes only the affected objective unavailable; clinical tables never become omics Blocks.

**CL-ADR02 — settle.** B owns all association fits and returns the common ClinicalAssociationResult; A owns typing/linkage, C score lineage/prediction, and D rendering. Between-person objectives fit prespecified adjusted feature/endpoint regressions. Two-occasion within-person objectives fit paired deltas; longer repeated objectives separate within-person deviation from between-person mean and use an approved repeated model. No automatic all-column adjustment, dichotomization, causal label or fallback correlation. A score trained on the clinical outcome may have a descriptive training association only.

**CL-ADR03 — settle.** `AssociationFamily` is fixed before fitting and records every declared member. For an otherwise valid family, use the tested p-value for estimable fits and a conservative internal value of 1 for failed/non-estimable members when applying BH; publish q only for estimable rows, keep failed-row q as NA, and record `adjustment_placeholder=1`, declared/evaluated/failed counts and reasons. If source selection, dictionary, family definition or model validity is unresolved, withhold all inferential q values. Report complete-case population and exclusions per cell; more general imputation requires pooled uncertainty and a separate approved method.

**CL-ADR04 — settle.** Every score association binds construction weights, fit/apply state, representation/unit map, training outcome and split history. Incremental clinical-only/molecular-only/combined prediction uses identical outer folds, fold-local processing and nested selection; reused evaluation data are recorded. Pathway/target links record subject/sample/fit-lineage overlap and never imply binding, causation or independent replication. Routine reports exclude direct identifiers and sensitive free text. The audience-specific minimum-cell and complementary-suppression threshold remains a user/institution policy fact.

## Source and identity settlement

Adopt `study_id` scoping; typed SourceArtifact regions; explicit orientation/header/column roles; audited external conversion; strict sample maps bound to source and metadata digests; and an immutable original observation mask with knownness. `feature_key` is the only join key and maps to Block, original ID, namespace, source row, measurement level, identification resolution, units/scale and parent lineage. Aliases are one-to-many evidence edges and never authorize coalescing. N source artifacts and N Blocks are unrelated cardinalities; integration accepts arbitrary N eligible Blocks, subject to backend minimums.

## Executable settlement tickets after adoption

1. **A-T01/A-T02 contracts:** add the shared schemas through the existing configuration/ingest vertical slice; serialize synthetic SourceArtifact, FeatureRegistry, AnalysisUnitMap, PreprocessingState and evidence references; reject stale hashes, namespace collisions, source conflicts and projected-out estimands.
2. **A-T07 fit/apply:** exercise each supported profile on train/apply partitions; mutate held-out values/outcomes and prove state/training output hashes do not change. Mark non-inductive methods unsupported for prediction. A-T08 retains reproduction/handoff.
3. **B-T03/B-T04 repeated:** hand-check two-occasion deltas; compare centered+fixed-subject coefficients/SE/df with the raw fixed-subject reference for supported >2-visit fixtures; run rank and null-calibration gates; refuse unsupported covariance patterns.
4. **C-03 DIABLO:** verify pinned NA patterns, joint sign orientation, equal-weight consensus prediction, finite success, variance extraction and selection labels against native objects.
5. **B-T06 and B-T08/B-T09 families:** freeze per-Block and clinical family manifests; inject failed fits and verify fixed denominator, internal p=1 treatment, published NA q and complete disposition accounting.
6. **D-T04 evidence:** send B and C nominations through both compatible routes; prove full-universe/rank checks, one-to-many mapping accounting, disabled-rights behavior and zero-result versus failure states.
7. **Clinical vertical slice:** use existing A-T09 → B-T08/B-T09 → C-08/C-09 → D-T15 for typed ingest, authoritative linkage, between/within associations, score-lineage refusal, matched nested prediction and disclosure-safe reporting.
8. **B-T07 reproduction boundary:** publish a machine-checkable Markdown method/reproduction record at milestone 4. Cross-cutting Quarto vignettes stay at milestone 9.
9. **A-T01 CLI contract:** freeze `Rscript inst/exec/triomics --config <path> --stage <A|B|C|D|all> --output <path>` plus `--validate-only`. Validation performs schema, source, dependency/capability and estimand checks without computing analyses; stage mode computes only the requested eligible stage and returns distinct invalid-input, unavailable-capability, partial and failed outcomes. These are future acceptance commands for files the implementer must create, not commands available or run now.

Production remains sequential A, B, C, D. No ticket starts until the language/runtime choice, protected amendments and required empirical gates are approved.
