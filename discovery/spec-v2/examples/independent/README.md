# Explicitly synthetic independent software fixture

Twelve fictional sample records; two fictional groups of six independent samples;
three blocks of ten deliberately synthetic features. No real molecular IDs,
participants or experimental instrument are represented. Positive data were
constructed with fixed seeds for source/schema/identity and future CLI tests.
No actual limma/PCA/DIABLO/MOFA run or method-performance result is supplied.

JSON and YAML configs are equivalent. Fixture q/effect thresholds, prevalence,
normalization and component counts are engineering examples, not recommended
settings for the user's study. After the pipeline is implemented, these can feed
the documented CLI. Schema validation now is not a pipeline execution claim.
