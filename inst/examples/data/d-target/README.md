# Synthetic target fixtures

These files exercise typed target identity, exact external-assay matching, file
hash provenance, and B/C feature lineage. Target labels, mechanisms, compounds,
assay records, and molecular links are software-test data only. They make no
claim about real proteins, drugs, binding, function, engagement, or metabolism.

The external records intentionally have no measured affinity value. `Kd` remains
unavailable unless a sourced assay record supplies its value and units.
