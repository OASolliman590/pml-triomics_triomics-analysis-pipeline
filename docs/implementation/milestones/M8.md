# M8 — offline report, clinical section and target dossier

The accepted packets render saved synthetic A/B/C/D evidence as local, self-contained HTML and machine-readable TSV/JSON. They do not refit models or establish biological or clinical validity. G7 was accepted previously. At this note's creation, G8 and G9 remain closed; packet acceptance is not milestone acceptance.

## Interfaces and safeguards

`render_report(report_bundle, report_spec)` verifies the versioned bundle, configuration and saved artifact lineage. The report CLI builds that bundle from one output root. `report_spec` permits only `output_relative_path = "report"`, and the destination must not already exist. Local Quarto and the fixed templates are required. The renderer writes HTML, tables, data, manifest and JSON envelopes; it preserves effects, units, families, counts, uncertainty and section status. Missing required producer files or the current D pointer abort rendering; an incomplete required section can yield a partial report. Unavailable optional routes remain visible.

The clinical and target providers take verified loaded evidence plus configuration and return a status, reason and tables. The clinical section displays dictionary/coverage, objectives, adjustments, saved effects, intervals, units, missingness, family accounting and score lineage. It distinguishes descriptive associations, qualified inference, held-out evaluation and unavailable objectives. Patient scores differ from contrast enrichment, and clinical associations do not establish target binding. It rejects clinical evidence absent from D's pinned B bundle. Direct identifiers and raw clinical free text are withheld, with guards for untrusted text and unsafe paths. Clinical release to the `approved_aggregate` audience is currently refused; an institution-approved minimum-cell and complementary-suppression policy implementation is required. Private local research reports stay local.

The target dossier presents binding, engagement, function and molecular-compatibility axes separately, with source, alternatives, contradictions, missing evidence and shared-subject/construction lineage. Same-study overlap is not independent replication. Discovery is unranked and exploratory; abundance or docking is not experimental binding or affinity. D-T14's quantitative method remains unavailable.

## Public fixture commands

From the source checkout root, with the recorded R dependencies and Quarto available and `TMPDIR` on local internal APFS, this creates a fresh D-T08 run. Stop on any failed stage; use the same config and output root for all stages. The prior native evidence used R 4.6.1 and Quarto 1.11.9; the commands below are reproduction instructions, not new results.

```sh
(
  TASK_RUN="$(mktemp -d "${TMPDIR:-/tmp}/triomics-m8.XXXXXX")" || exit $?
  TASK_CONFIG=inst/examples/tickets/D-T08.yaml
  printf 'Run directory: %s\n' "$TASK_RUN/output"
  for stage in A B C D report; do
    Rscript --vanilla inst/exec/triomics --config "$TASK_CONFIG" --stage "$stage" --output "$TASK_RUN/output" || exit $?
  done
)
```
