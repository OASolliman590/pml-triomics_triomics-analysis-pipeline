# M7 — annotation and target investigation

On public synthetic fixtures, the software carries molecular and integration evidence into local lipid and gene-product mapping, describes mapping ambiguity, and calculates over-representation against a declared measured background. It records unavailable resources and assembles unranked target evidence profiles, keeping external assays, shared observations and unmeasured evidence distinct. Species applicability uses taxon declared in Stage D metadata and its recorded origin; it is not an invented B/C measurement ancestor. These software checks do not establish pathway activation, direct binding, causation, biological validity or clinical validity. No real study data were analyzed.
