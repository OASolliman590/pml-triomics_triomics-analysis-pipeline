# M7 — annotation and target investigation

On synthetic fixtures, the software can carry molecular and integration evidence into local lipid and gene-product mapping, describe mapping ambiguity, and calculate over-representation against a declared measured background. It can record unavailable resources and assemble unranked target evidence profiles, keeping external assays, shared observations and unmeasured evidence distinct. These checks do not establish pathway activation, direct binding, causation, biological validity or clinical validity. No real study data were analyzed.
