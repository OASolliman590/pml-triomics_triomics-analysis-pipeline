Acceptance: **pending**. This note documents evidence for M6; it does not accept
M6, release G6, or open Stage D. The milestone requires C-03, C-04, C-05, C-08,
C-09 and C-06 evidence, with the conditional scope retained as specified in the

## Implemented interfaces and limits

- **C-03/C-04:** categorical DIABLO uses native `mixOmics::block.splsda`; scalar
  continuous response uses `mixOmics::block.spls`. Shared predictor scores and
  transforms follow the frozen training-only consensus rules; C-03 variance
  uses verified native predictor-block proportions, and native predictions
  remain separate. Sol accepted both packets on synthetic software evidence:
  82 C-03 and 132 C-04 expectations passed. Fixture predictions are not
  biological performance estimates. ([Stage C contract](../../../discovery/spec-v2/C_INTEGRATION.md), [packet cards](../../../discovery/spec-v2/packets/C-03.md), [C-04](../../../discovery/spec-v2/packets/C-04.md), [acceptance](../reviews/2026-10-20-c03-c04-sol-acceptance.md))
- **C-05:** the isolated MOFA2/mofapy2 route trains, saves, reloads and compares
  seeded fits; prediction is explicitly unsupported. It remains exploratory
  structure discovery, with no qualified unseen-subject predictive route. Sol
  accepted it on synthetic software evidence only. The focused suite passed 141
  expectations with 15 warnings, including native MOFA diagnostics; warnings
  were preserved. ([C-05 card](../../../discovery/spec-v2/packets/C-05.md), [acceptance](../reviews/2026-10-20-c05-sol-acceptance.md))
- **C-08/C-09:** C-08 exports immutable score endpoints and schedules a separate
  B-owned clinical association request. C-09 is conditional and its integrated
  registry is complete only for `synthetic_fixture_only`, with
  `benefit_guaranteed=false`. It does not qualify a real endpoint, clinical
  deployment, uncertainty protocol, independent clinical validation,
  biological validity, or benefit. Sol accepted C-08; C-09 is integrated and
  verified but remains M6-pending. C-08's focused suite passed 288 expectations.
  C-09 shared and packet suites passed 71 and 124 expectations; its CLI result
  remains synthetic-only. ([C-08 card](../../../discovery/spec-v2/packets/C-08.md), [C-09 card](../../../discovery/spec-v2/packets/C-09.md), [C-08 acceptance](../reviews/2026-10-20-c08-sol-acceptance.md), [C-09 integration verification](../reviews/2026-10-21-c09-shared-integration-verification.md))
- **C-06:** cross-backend comparisons preserve comparable context and distinguish
  native from common evidence in the D handoff. Integrated tests and synthetic
  CLI read-back passed, but C-06 remains M6-pending. Its handoff explicitly
  records C-07 controls as `not_run`; it is partial and supplies no control
  metrics. The focused C-06 suite passed 290 expectations. ([C-06 card](../../../discovery/spec-v2/packets/C-06.md), [integration verification](../reviews/2026-10-21-c06-shared-integration-verification.md))
