The current [LIPID MAPS entry](https://www.lipidmaps.org/resources/tools/38?task=7.3) points to [PKD6B/files](https://osf.io/pkd6b/files) and calls the licence `GNU GPL 3.0 (academic)`. Its [documentation](https://www.lipidmaps.org/tool/biopan/doc/index.html) describes the hosted interface and integration with LipidLynxX; it does not establish an offline installation route.

On this date the web tool returned **403** for the linked OSF files page and readme; it could not open the DOI destination or the [public node API](https://api.osf.io/v2/nodes/pkd6b/). These observations concern the available tool and network, not every user's access or the reason for denial. No account or access controls were changed. The archive, original readme, exact included licence notices, component inventory, and bundled-reference terms could not be read; no archive version or SHA-256 can be reported. The paper's licence label and the directory's parenthetical do not settle which terms apply to each component or contemplated operation.
